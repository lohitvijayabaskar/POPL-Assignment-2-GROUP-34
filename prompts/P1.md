# P1 prompts

Tool: Claude Code (Claude Opus 5.5), desktop app

Note: the wording of these prompts was drafted earlier in the same Claude session.

## Prompt 1 (commit: P1: candidate/1 generator for the puzzle)

Follow skills/prolog-dev/SKILL.md. In a new file code/_q1.pl, write only a predicate candidate(S) that generates every possible filled-in assignment for this puzzle: four friends 'Alex', 'Ben', 'Carla', 'Dana'; departments research, development, design, testing; languages python, java, 'c++', javascript; projects 'AI', web, embedded, data; each value used exactly once per attribute. S is a list of four p(Name, Dept, Lang, Project) terms in the order Alex, Ben, Carla, Dana. Use permutation/2 from library(lists). Do not write the clues or main yet.

## Prompt 2 (commit: P1: clue/2 clauses for clues 1-8)

Follow skills/prolog-dev/SKILL.md. In code/_q1.pl, add only clue(N, S) clauses for N = 1..8, each succeeding exactly when that clue holds in a fully ground solution S (list of p(Name, Dept, Lang, Project)). Put the English clue in a comment above each clause. Clues: 1. The friend who prefers the AI project does not work in research and is not Dana. 2. Alex does not work in development and does not prefer C++. 3. The friend working in the testing department likes Python. 4. Ben prefers web projects and does not work in testing. 5. The friend whose favorite language is Java works in the design department. 6. Carla's project preference is not embedded, and her department is not development. 7. Dana's favorite language is not Java, and she works in research or testing. 8. The friend who prefers data projects works in research and does not use JavaScript. Make sure no clause can succeed more than once for the same S.

## Prompt 3 (commit: P1: satisfies/2 checks a list of clues)

Follow skills/prolog-dev/SKILL.md. In code/_q1.pl, add only satisfies(Active, S): it succeeds when every clue number in the list Active holds for the ground solution S, using the existing clue/2. It must be deterministic (succeed at most once per S), because it will be used inside counting. Do not write main yet.

## Prompt 4 (commit: P1.a: main/0 derives and prints one solution)

Follow skills/prolog-dev/SKILL.md. In code/_q1.pl, add only main/0 (plus a small printing helper if needed). It uses candidate/1 and satisfies/2 to find one solution of clues 1 to 8 and prints it as four lines in exactly this format, in the order Alex, Ben, Carla, Dana: Alex = [research, python, AI] (department, language, project; atoms printed without quotes). The answer must be derived from the clues, not hard-coded. Do not call halt and do not add an initialization directive.

## Prompt 5 (commit: P1.b: count_solutions/2)

Follow skills/prolog-dev/SKILL.md. In code/_q1.pl, add only count_solutions(Active, N): N is the number of candidates that satisfy all clue numbers in the list Active and ignore all other clues. Use aggregate_all/3 or findall/3. Then run count_solutions([1,2,3,4,5,6,7,8], N), list the solutions it counts, and tell me what the value of N says about the puzzle. I will write P1_REPORT.md myself from your answer.
