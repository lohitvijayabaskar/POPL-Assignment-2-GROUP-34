## Prompt 1 (commit: P2: expr/3 builds expression trees with exact division)

Follow skills/prolog-dev/SKILL.md. In a new file code/34_q2.pl, write only expr(Nums, Tree, Value): Tree is an expression that uses every integer of the non-empty list Nums exactly once and in order, and Value is its integer value. An expression is a single number or two expressions joined by +, -, * or /. Split Nums into two non-empty parts in every possible way. Division is allowed only if the divisor is non-zero and the division is exact; it applies to every division in the tree. Values may be negative. Evaluate while building the tree; never build a string and parse it back. No unary minus, no joining digits.

## Prompt 2 (commit: P2: canonical printer to_string/2)

Follow skills/prolog-dev/SKILL.md. In code/34_q2.pl, add only to_string(Tree, String) that prints an expression tree as an SWI-Prolog string with no spaces, using these rules: * and / bind tighter than + and -; a left operand is in parentheses only if its top operator has lower precedence than its parent's; a right operand is in parentheses if its top operator has the same or lower precedence; a number is never in parentheses. It must give: (4+2)*3, 4+2*3, 8/4*2, 8/(4*2), 1-2-3, 1-(2-3), 1+(2+3), 1+2+3 for the matching trees.

## Prompt 3 (commit: P2.a: generate_equation/2)

Follow skills/prolog-dev/SKILL.md. In code/34_q2.pl, add only generate_equation(List, Equation): Equation is a string "L=R" where L is an expression over the first j numbers and R over the rest (1 <= j < length), both with the same value, printed with to_string/2. It must fail (not loop, not raise an error) when no equation exists, including for lists of length 0 or 1. Avoid recomputing the right side's trees for every left tree.
