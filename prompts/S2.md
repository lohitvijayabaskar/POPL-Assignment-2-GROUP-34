# S2 prompts

Tool: Claude Code (Claude Sonnet 5.5), desktop app

Note: the wording of these prompts was drafted earlier in the same Claude session.

## Prompt 1 (commit: S2.b: my-length)

Follow skills/scheme-dev/SKILL.md. In a new file code/34_q4.rkt starting with #lang racket/base, write only (my-length lst), the number of top-level elements of lst, using only the allowed built-ins. Make it tail-recursive so lists of 10,000 elements work.

## Prompt 2 (commit: S2.b: my-map)

Follow skills/scheme-dev/SKILL.md. In code/34_q4.rkt, add only (my-map f lst), which returns the list of (f e) for each element e of lst, in order, using only the allowed built-ins. Make it tail-recursive so lists of 10,000 elements work (a small my-reverse helper is fine, since reverse is forbidden).

## Prompt 3 (commit: S2.b: first insert-if-short)

Follow skills/scheme-dev/SKILL.md. In code/34_q4.rkt, add only (insert-if-short x lst n), defined using my-length and my-map, which inserts atom x at the front of every list (at every level of nesting, including the top level and empty lists) whose length is less than n. The length is the number of top-level elements of the ORIGINAL list, before insertion. Use my-length and my-map. Example: x=42, lst=((1 2) (3 4 5) (6) ()), n=3 gives ((42 1 2) (3 4 5) (42 6) (42)).

## Prompt 4 (commit: S2.a: print-insert-result reads from stdin)

Follow skills/scheme-dev/SKILL.md. In code/34_q4.rkt, add only (print-insert-result), which takes no arguments, reads x, lst and n from standard input with read in that order, and displays the result of insert-if-short followed by a newline, with no prompt or other text.
