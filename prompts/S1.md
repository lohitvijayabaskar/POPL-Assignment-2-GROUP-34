# S1 prompts

Tool: Claude Code (Claude Sonnet 5.5), desktop app

Note: the wording of these prompts was drafted earlier in the same Claude session.

## Prompt 1 (commit: S1: inorder traversal with an accumulator)

Follow skills/scheme-dev/SKILL.md. In a new file code/34_q3.rkt starting with #lang racket/base, write only (inorder-acc tree acc), which returns the inorder list of the tree's values (left subtree, node, right subtree) consed in front of acc. A tree is () or a three-element list (value left right). Use the accumulator so no append is needed; small accessor helpers for value/left/right are fine.

## Prompt 2 (commit: S1: preorder traversal with an accumulator)

Follow skills/scheme-dev/SKILL.md. In code/34_q3.rkt, add only (preorder-acc tree acc), which returns the preorder list (node, left subtree, right subtree) consed in front of acc, built with the accumulator and without append, in the same style as inorder-acc.

## Prompt 3 (commit: S1: postorder traversal with an accumulator)

Follow skills/scheme-dev/SKILL.md. In code/34_q3.rkt, add only (postorder-acc tree acc), which returns the postorder list (left subtree, right subtree, node) consed in front of acc, built with the accumulator and without append, in the same style as inorder-acc.
