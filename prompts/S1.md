## Prompt 1 (commit: S1: inorder traversal with an accumulator)

Follow skills/scheme-dev/SKILL.md. In a new file code/34_q3.rkt starting with #lang racket/base, write only (inorder-acc tree acc), which returns the inorder list of the tree's values (left subtree, node, right subtree) consed in front of acc. A tree is () or a three-element list (value left right). Use the accumulator so no append is needed; small accessor helpers for value/left/right are fine.

## Prompt 3 (commit: S1: postorder traversal with an accumulator)

## Prompt 4 (commit: S1: height)

Follow skills/scheme-dev/SKILL.md. In code/34_q3.rkt, add only (height tree). The height of () is 0, and the height of a node is 1 plus the larger of the heights of its two subtrees, so a single node has height 1.
